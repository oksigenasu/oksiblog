Satsun service is BACK!!  
  
Todays repair are sponsored by [@thisislingga](https://www.instagram.com/thisislingga/). this Logitech mouse was found with the wrong receiver. having a lost receiver for a wireless mouse is a common tragedy. but fear not! for this is the expensive M280 Logitech Wireless mouse with unifying receiver dongle!  
  
with this dongle, you can pair another Logitech mouse even if its from another breed! to do that, you only need pairing software from logitech, or if you're on linux (like i) use Solaar.  
  
to start pairing, plug the USB receiver into the computer and fire up Solaar. you can see this dongle is already paired with M187 mouse before. so, to pair it with the M280, select on the "Nano Receiver" Menu and then click on "+ Pair new device". after that a pop up window will show you how to start pairing and how many times this receiver dongle can be paired.  
  
After pairing, it shows the current paired mouse (M280/320/275) and other informations like battery level and mouse sensitivity.  
  
This trick as far as i know is only viable on logitech peripheral. other brands rarely have this kind of support (looking at you, chinesium stuffs!).  
  
so if you have missing dongle on Logi wireless mouse, rejoice! just take one from another mouse!
